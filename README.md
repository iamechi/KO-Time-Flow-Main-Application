<h4>Project Goal & Overview</h4><br/>
Right now, there are many applications that promoters use to match make and manage their fights. However, many of those applications serve many different functions, which increase their complexity, and complexity makes using applications complicated. However, what if you could have an application that just focused on one thing: scheduling fights? That's what K.O. Time Flow aims to do-focus squarely on designing an application that handles that goal and handles it well.<br/>
<br/>
There will be 5 main microservices of this application. The fighter management microservices gives you the ability to add, update, and search for fighters and their information. It will provide stats of the fighter, which can inform what fights sed fighter can and should be scheduled for. The second section of this application will be the area management application. Through this microservice, users can add new areas and update their avaiilability, capacity, and all relevant information that will help users choose the area that's best for scheduling the fights that they want to happen and when. The third microservice, which will be the meat of the entire application, will be the fighter scheduler microservice. That will handle the scheduling of the fighters at specific areas, provide information about already scheduled fights, let you swap out fighters or areas for scheduled fights if necessary, and any other needed functionality that a fight scheduling application should provide. The finances microservices, will handle the financial side of things, such fight costs, fighter pay, and expected revenue and expenses from delivered fights. Finally, there will be the calendar microservice, which will provide an easier way to see which fights have been schedule on which date and time. All of these microservices will come together to form the application that will make our expected clientele's lives so much easier.<br/>
<br/>
This application is lightweight in design since a smaller project means less in terms of memory and server communication, which will keep costs down. To do this, Spring Boot and Docker will be the architectural foundation for this application. The backend will be built through Spring Boot Java microservices, meaning each of the main screens will have their own microservice to handle the business logic for that section of the application. All of these microservices, however, will communicate to one AWS RDS instance that the database will be hosted on. The application will be hosted on a single EC2 instance to maintain a simple architecture, but also designed in a way that it can be scalable when and if it is needed. Each of these Spring Boot microservices will be containerized through Docker, which will be great at preventing exceptive memory consumption and slow performance due to the avoidance of relying much larger VMs to run the application. Dependencies will also be easier to manage through Docker, which can prevent maintance struggles that can lead to excess time(and money) wasted on fixing or debugging. All of these docker containers will be managed through a docker-compose.yml, which will make the management of these applications simpler as well. As for the frontend, that will be designed through the use of REACT framework and Typescript language. This application will also be containerize as well and send and receive data from the microservice applications. Overall, the goal of using each of these technologies is simple: use a lightweight, fast, technology stack to provide quick, cost-efficient service to our users.<br/>
<br/>
This project can be useful to many promoters, especially smaller, more regional promoters that maybe can't afford to use the larger applications or don't have enough resources to properly manage them. Applications like this can give them a affordable and easily usable tool that will make their lives easier rather than more difficult. Since this application will be designed to be scalable it can still be a powerful tool for when smaller promoters become larger in size. Overall, the benefits of this application make it a powerful tool for smaller promoters and big promoters, and will give anyone who uses it and undeniable edge in the space of fighter promotion.<br/>
